Advanced Finance Tracker

This page explains what data the tracker stores and how users can control it.

Back to App

Data Stored

The application stores transaction entries, theme preference, language preference, and cookie banner choice in the browser's LocalStorage. This keeps the app usable after refresh without sending finance data to a server.

Cookies and Tracking

The application does not use analytics, advertising, or third-party tracking cookies. The cookie banner records whether the user accepted or declined local storage preferences.

User Control

  • Use the delete controls to remove individual transactions.
  • Clear browser site data to remove all LocalStorage records for this app.
  • Export transactions as CSV before clearing data if needed.
